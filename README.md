# docx-gen

CLI-утилита для генерации .docx документов по ГОСТ-стилю:
Times New Roman 14, полуторный интервал, красная строка, поля 3/1.5/2/2 см.

Используется для массового оформления рефератов, отчётов и списков —
текст на входе, готовый Word на выходе.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
python docx_gen.py \
  --title "Реферат на тему ИИ" \
  --author "Иванов И.И." \
  --section "Введение" "Текст введения..." \
  --section "Заключение" "Текст заключения..." \
  --out referat.docx
```

Несколько `--section` добавляют разделы в том же порядке.
